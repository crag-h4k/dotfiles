# OpenCode setup

- A shared color palette connects the terminal, editor, tmux, and AI tools.
- The footer shows project, Git changes, model, activity, context, and cost.
- Provider quota appears at the right edge when quota data is available.
- Session tabs keep work accessible: Ctrl+X then H/J/K/L or the arrow keys switch
  tabs; Ctrl+X then T opens the session list.
- Activity indicators distinguish foreground work from running subagents.
- Inside tmux, pane colors signal when a session needs attention.
- Machine-specific configuration lives in private overrides.
